# The `<dir>/<year>/` folder for a figure's files, creating it if needed

Shared by
[`.save_fig_files()`](https://tuottavuuslautakunta.github.io/fiprod/reference/dot-save_fig_files.md)
and
[`.save_fig_data_file()`](https://tuottavuuslautakunta.github.io/fiprod/reference/dot-save_fig_data_file.md).

## Usage

``` r
.fig_year_dir(dir, year)
```

## Arguments

- dir, year:

  The `dir` and `year` of a settings list such as
  [`fig_defaults()`](https://tuottavuuslautakunta.github.io/fiprod/reference/set_fig_defaults.md),
  [`fig_captioned_defaults()`](https://tuottavuuslautakunta.github.io/fiprod/reference/set_fig_captioned_defaults.md)
  or
  [`fig_data_defaults()`](https://tuottavuuslautakunta.github.io/fiprod/reference/set_fig_data_defaults.md).
